git init: khởi tạo git, git bắt đầu nhận diện thư mục 
git add <file name>: add file <file name> vào vùng staging
git add . : add tất cả các file đang có vào vùng staging
git commit -m "message": dán nhãn có lần thay đổi được đẩy lên stag này có tên là "message"
